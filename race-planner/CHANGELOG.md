# 更新紀錄

## v1.5.0（2026-10-04）
- 新增「自動移動速度 %」（10～200，預設 100）：上方工具列可直接輸入或按 80%／100%／120%，「套件與感測器」也有同一個設定。
- 所有路徑移動（含弧線、超音波測距中斷）都乘上這個比例；程式碼產生 `const int AUTO_SPEED` 與 `autoV()`，燒錄前也能直接改數字。
- 模擬時間與賽規檢查同步換算；速度超過 130% 時提醒煞車距離變長、輪子容易打滑。
- 與程式產生器共用同一套寫法（產生器的競賽自動化同步加入）。

## v1.4.2（2026-10-04）
- 程式碼開頭說明依「自動做完後」設定顯示，不再一律寫「做完停在 AUTO OK」。

## v1.4.1（2026-10-04）
- 修正：勾選 BNO055 但感測器沒接好（序列埠一直出現 `EasyBNO055 error, resetting`）時，`bno.start()` 會無限等待，程式卡在開機：OLED 白屏、PS3 連不上、按鍵沒反應。現在開機先用 `bnoFound()` 偵測 I2C 位址 0x28，找到才 `bno.start()`；找不到時 `turnTo()` 直接跳過，其他功能照常。
- 賽規檢查新增：勾選 BNO055 但路徑沒有轉正步驟時，建議取消勾選。

## v1.4.0（2026-10-04）
- 與課程網站「程式產生器」同步：程式碼改用產生器的共用產生核心，寫法完全相同（`runAuto()`、`abortAuto()`、`remoteControl()`、`turnTo(角度, 誤差, 逾時)`、`frontDistCm()`）。
- 「感測元件」改為「套件與感測器設定」：水平雲台、手臂 ATARM、發射器 PPGUN、超音波、BNO055、PS3、V7RC、IR 靠牆校正，腳位與初始化和產生器相同；手臂與發射器擇一（ATARM.h、PPGUN.h 同時 include 會編譯失敗）、PS3 與 V7RC 擇一。
- 遙控：搖桿／方向鍵功能、移動與旋轉速度、死區、瞄準速度、官方按鍵配置（手臂車／發射車）；V7RC 支援藍牙與 Wi-Fi。
- 一鍵自動／手動模式：路徑變成一鍵自動流程，預設 START 自動、SELECT 手動，做完停在 AUTO OK 等裁判確認；每個步驟做完檢查手動鍵可中止；OLED 顯示模式、切換時手把震動。
- 新增到點動作：撞牆校正、超音波接近、連續發射、砲台旋轉、砲管仰角；撞牆校正與超音波接近會在畫布上模擬推進位置（藍色虛線）。
- 新增快速範本：撞牆校正→轉正、超音波接近→夾取→後退、放置→後退、IR 校正→轉正、砲台回正→連續發射。
- IR 校正改用新版積木寫法（主校正 左／右／無，可設逾時與確認時間）；超音波測距中斷改用 `stopNear_N()`。
- 移除夏普紅外線與 HuskyLens（程式產生器未收錄）；舊版方案匯入時自動轉成新的套件設定。
- 六種組合與瀏覽器實際產生的程式以 ESP32 核心 3.1.3、兔比函式庫編譯，0 錯誤 0 警告；其中最完整的兩組（IR 靠牆校正＋超音波中斷＋撞牆＋接近＋PS3＋OLED＋BNO＋手臂＋一鍵自動，以及 V7RC＋發射器＋連續發射＋一鍵自動）也在兔比積木線上 Arduino IDE（tubitblock.trgreat.com）實際編譯成功。
- 發射車的 V7RC 藍牙名稱預設改為官方範例的 `MTC_PPGUN_U01`（手臂車為 `MTC_ARM_U01`）。

## v1.3.1（2026-10-02）
- 到點動作工具列與步驟工具列新增「下降」按鈕（降到「參數」中的夾取高度）。

## v1.3.0（2026-10-02）
- 到點動作工具列可逐一刪除動作、直接修改角度（抬升、旋轉夾爪、BNO 轉正、等待）。
- 可設定路徑點車頭角度（輸入、0°／90°／180°／-90°、±15°）。
- 未勾選元件的步驟自動改成註解略過，避免編譯錯誤，並在賽規檢查提示。
- 以 ESP32 核心 3.1.3 與兔比積木函式庫實際編譯驗證六種組合。
