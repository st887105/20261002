STEP 1　開始使用

認識 TU:bit V2 控制板、安裝 TubitBlock，並把第一支程式上傳到機器人。

本頁目錄 1. 認識控制板 2. 安裝 TubitBlock 3. 加入 TU:bit V2 設備 4. 連線與上傳 5. 加入擴充積木 6. 第一支程式：按鈕與 OLED 常見問題

1. 認識 TU:bit V2 控制板

控制板就像機器人的電腦：讀取輸入（按鈕、超音波、手把），經過程式處理，再驅動輸出（馬達、伺服馬達、OLED）。TU:bit V2 以 ESP32 為核心，內建藍牙與 Wi-Fi，可直接用手機或 PS3 手把遙控。

2. 安裝 TubitBlock

  1. 到官網軟體下載點「兔比積木 TubitBlock」，下載 TubitBlock_v版本_win_x64.exe 並安裝。
  2. 安裝 USB 驅動：控制板在電腦上會顯示為 USB-SERIAL CH340（COMx）。若裝置管理員看不到這個 COM 埠，請安裝 CH340 驅動（官方講義 01「TU:bitBlock 驅動安裝」）。
  3. 更新 TubitBlock 版本後，請開啟軟體 › 設定 › 清除緩存並重啟，避免舊的擴充積木殘留。
  4. 不方便安裝時，可改用 TubitBlock 線上版，或把產生的程式碼貼到 兔比積木 Arduino IDE 線上版 編譯燒錄。
補充環境設定的完整圖文說明在 TU Wiki：TubitBlock 入門。

3. 加入 TU:bit V2 設備

  1. 開啟 TubitBlock，點左上角的「未選擇設備」。
  2. 第一次使用需先安裝 TU:bit 設備資料庫，再選 TU:bit V2 控制板。
  3. 加入後左側會出現 TU:bit V2 的功能分類（按鈕、OLED、馬達、伺服馬達等）。

4. 連線與上傳

  1. 用 USB 線接上控制板，按「連線」。
  2. 清單中選 USB-SERIAL CH340（COMx），按「開始連線」。看不到裝置時按「重新整理」，或勾選「顯示全部可連接的設備」。
  3. 拼好積木後按「上傳」，等待編譯與燒錄完成。
  4. 要看感測器數值，打開序列埠監控視窗（程式中需有序列埠列印積木）。
上傳失敗時先確認 USB 線是可傳資料的線（不是只能充電的線），再確認 COM 埠沒有被其他軟體（例如另一個 TubitBlock 視窗或序列埠工具）占用。

5. 加入擴充積木

PS3 手把、V7RC、MTC 麥克納姆輪、手臂（ATARM）、乒乓球發射器（PPGUN）、BNO055 等功能都在「擴充功能」裡。點左下角的擴充功能按鈕，選擇要用的模組後，左側就會多出對應的積木分類。用法見 擴充模組。

6. 第一支程式：按鈕與 OLED

先做一支不需要接任何零件的程式，確認連線與上傳都正常。

當 Arduino 啟動 TUBIT 初始化 重複無限次 OLED 開始繪圖 OLED 顯示文字 X=0 Y=16 「按鈕 A：」＋ 讀取按鈕 A OLED 顯示文字 X=0 Y=40 「按鈕 B：」＋ 讀取按鈕 B
  • 按鈕狀態：0＝未按下、1＝按下（官方講義 03）。
  • OLED 顯示文字的座標點在文字左下角，畫面範圍 (0,0) 到 (128,64)，所以第一行 Y 要設 16 左右才看得到（官方講義 04）。
  • 控制 OLED 需要「OLED 開始繪圖」，或「更新顯示器＋清空顯示器」。
